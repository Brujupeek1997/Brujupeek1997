## Currently Working On

> ### From Bark to Byte
>
> **An active computer-vision research pipeline for real multi-view timber imagery.**
>
> Converts scanner composites into traceable, metadata-linked crops and QA-gated segmentation masks through deterministic preprocessing, pretrained TimberVision inference, view-aware selection, and auditable reports. The pipeline supports CUDA inference with a CPU fallback.
>
> `Python` · `Multi-view imagery` · `Segmentation` · `CUDA` · `Data QA`
>
> <a href="https://brujupeek1997.github.io/logClassifierWeb/"><img alt="Open the live From Bark to Byte project" src="https://img.shields.io/badge/VIEW_PROJECT-0969DA?style=for-the-badge&amp;logo=githubpages&amp;logoColor=white"></a> <img alt="Private source" src="https://img.shields.io/badge/SOURCE-PRIVATE-30363D?style=for-the-badge&amp;logo=github&amp;logoColor=white">

## Featured Engineering

> ### GuidanceAR
>
> **Unity-to-Python AR guidance prototype.** Phone keyframes are processed by a Flask and YOLO11 service that returns detections, bounding boxes, and confidence values; the project also covers synthetic-data generation, training, validation, and inference experiments.
>
> `Python` · `Flask` · `YOLO11` · `OpenCV` · `Unity`
>
> <a href="https://github.com/Brujupeek1997/GuidanceAR"><img alt="Open the GuidanceAR repository" src="https://img.shields.io/badge/REPOSITORY-21262D?style=for-the-badge&amp;logo=github&amp;logoColor=white"></a> <a href="https://github.com/Brujupeek1997/GuidanceAR/blob/main/phone.mp4"><img alt="Watch the GuidanceAR phone demo" src="https://img.shields.io/badge/WATCH_DEMO-0969DA?style=for-the-badge&amp;logo=youtube&amp;logoColor=white"></a>

> ### BrickWorth Pricing Pipeline
>
> **Nightly, dependency-free Python data pipeline.** Collects BrickLink listings, normalizes prices with ECB exchange rates, separates item conditions, and publishes confidence-aware JSON snapshots only when the output changes.
>
> `Python 3.11` · `Data Integration` · `JSON / XML` · `GitHub Actions`
>
> <a href="https://github.com/Brujupeek1997/prices-repo"><img alt="Open the pricing pipeline repository" src="https://img.shields.io/badge/REPOSITORY-21262D?style=for-the-badge&amp;logo=github&amp;logoColor=white"></a> <a href="https://brujupeek1997.github.io/prices-repo/prices.json"><img alt="Open the published pricing data" src="https://img.shields.io/badge/LIVE_DATA-0969DA?style=for-the-badge&amp;logo=json&amp;logoColor=white"></a>
