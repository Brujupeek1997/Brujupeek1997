## Selected Work

### [BrickWorth Pricing Pipeline](https://github.com/Brujupeek1997/prices-repo)

Automated Python pipeline that collects marketplace listings, converts currencies using ECB exchange rates, separates prices by item condition, and publishes JSON snapshots with confidence metadata. It uses official retail pricing when marketplace data is unavailable; a scheduled GitHub Actions workflow regenerates the dataset and commits only material changes.

`Python 3.11` · `JSON / XML` · `GitHub Actions` · `GitHub Pages`

[Published data →](https://brujupeek1997.github.io/prices-repo/prices.json)

### [China Quest Map](https://github.com/Brujupeek1997/ch_react)

Responsive React itinerary interface with a generated SVG journey path, persistent per-stop progress, theme support, and animated detail views. Vite builds and GitHub Actions provide a lightweight static delivery pipeline.

`React 19` · `JavaScript` · `Vite` · `Tailwind CSS` · `Framer Motion`

[Live demo →](https://brujupeek1997.github.io/ch_react/)
